# BooksCollector — Unit Tests

В проекте реализованы юнит-тесты для класса `BooksCollector` с использованием `pytest`.

## Покрытые методы и сценарии

### add_new_book
- добавление новой книги
- проверка пустого жанра у новой книги
- проверка длины названия (параметризация)

### set_book_genre / get_book_genre
- установка корректного жанра
- невозможность установить некорректный жанр

### get_books_with_specific_genre
- получение книг с определённым жанром

### get_books_genre
- получение словаря книг и жанров

### get_books_for_children
- исключение книг с возрастным рейтингом

### favorites
- добавление книги в избранное
- невозможность добавить книгу дважды
- удаление книги из избранного
- получение списка избранных книг

## Запуск тестов

```bash
pytest -v tests.py
